# Обработка списка треугольников

Программа работает с треугольниками на плоскости, используя классы `Point` и `Triangle` для хранения координат и геометрических вычислений, а также собственный односвязный список `List`.

Программа читает входные данные из файла `input.txt`, проверяет их корректность с помощью регулярных выражений (`std::regex`), отфильтровывает невалидные треугольники, вычисляет их периметр и площадь, определяет равнобедренные треугольники и записывает результат в `output.txt`.

## Структура проекта

```text
.
├── CMakeLists.txt      # Корневой файл сборки
├── main.cpp            # Точка входа
├── input.txt           # Входные данные
├── include/            # Заголовочные файлы (point.h, triangle.h, list.h)
├── src/                # Реализация библиотеки geometry и её CMakeLists.txt
└── tests/              # Модульные тесты (doctest.h, test.cpp) и их CMakeLists.txt
```

## Формат входных данных (`input.txt`)

* В первой строке указывается целое положительное число `n` — количество треугольников.
* В следующих `n` строках задаются координаты трёх вершин треугольника: `x1 y1 x2 y2 x3 y3` (целые или вещественные числа через пробел).
* При несоответствии формату программа завершает работу с сообщением об ошибке и номером строки.

### Пример `input.txt`

```text
5
0 0 3 0 0 3
1 1 4 1 1 5
0 0 1 1 2 2
2 2 5 2 2 6
0 0 0 0 1 1
```

## Сборка и запуск

Требуется CMake версии 3.20+, компилятор с поддержкой C++20 и доступ в интернет при первой сборке (для автоматической загрузки `Boost.Program_options` через `FetchContent`).

Откройте терминал в корневой директории проекта и выполните:

```bash
# Генерация файлов сборки
cmake -S . -B build

# Компиляция проекта и тестов
cmake --build build
```

### Запуск основной программы

```bash
# Windows
.\build\proga.exe

# Linux / macOS
./build/proga
```

### Запуск тестов

```bash
ctest --test-dir build --output-on-failure
```

Или напрямую:

```bash
# Windows
.\build\test_proga.exe

# Linux / macOS
./build/test_proga
```

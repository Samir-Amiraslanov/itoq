# Обработка списка треугольников
*Программа работает с треугольниками,используя классы Point и Triangle для хранения координат. Для хранения треугольников написан собственный класс **List**. Программа читает входные данные из фалйа ,*
*отфильтровывает невалидные треугольники,вычисляет их площадь и периметр определяет равнобедренные треугольники и записывает результат в выходной файл*


## Формат входных данных (`input`)
* В первой строке указывается целое число `n`- кол-во треугольников
* В следующих `n` строках задаются координаты трех вершин треугольника (`x1 y1 x2 y2 x3 y3`)
#### Пример `input` 
```
5
0 0 3 0 0 3
1 1 4 1 1 5
0 0 1 1 2 2
2 2 5 2 2 6
0 0 0 0 1 1
